# مدار iOS

تم تحويل منطق ملف HTML الحالي إلى تطبيق iOS أصلي باستخدام SwiftUI.

## التشغيل
1. افتح `Madar.xcodeproj` في Xcode.
2. اختر Target `Madar` ثم `Signing & Capabilities`.
3. اختر فريق Apple Developer الخاص بك واضبط Bundle Identifier إذا لزم.
4. اضغط `+ Capability` واختر `Background Modes`.
5. تأكد من تفعيل `Background fetch`.
6. شغّل التطبيق على iPhone حقيقي، واسمح بالإشعارات عند أول تشغيل.

> المشروع يحتوي بالفعل على `UIBackgroundModes = fetch` و `BGTaskSchedulerPermittedIdentifiers` في `Info.plist`، لكن يُفضّل فتح تبويب Signing & Capabilities في Xcode والتأكد من ظهور Background Modes بشكل صحيح بعد اختيار فريق التوقيع.

## الإشعارات
- التطبيق يرسل إشعارًا محليًا عند اكتشاف إشارة جديدة لم يتم إشعارك بها سابقًا.
- لا يكرر الإشعار لنفس العملة ونفس شمعة الإشارة.
- الفحص كل 5 دقائق يعمل أثناء فتح التطبيق إذا كان خيار التحديث التلقائي مفعّلًا.
- في الخلفية يتم استخدام `BGAppRefreshTask`. iOS يحدد وقت التنفيذ فعليًا؛ النظام لا يضمن تشغيل التطبيق كل 5 دقائق عندما يكون مغلقًا أو في الخلفية.

## البيانات
يستخدم التطبيق واجهات Binance العامة فقط، ولا يحتاج API Key ولا يتصل بحساب تداول ولا ينفذ أوامر.
